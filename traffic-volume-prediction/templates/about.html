About This Project

A machine learning–powered traffic volume prediction system developed as a B.Tech Civil Engineering project.

🚦 Project Overview

The Traffic Volume Prediction System uses historical traffic and weather data to predict the hourly traffic volume on a major interstate highway. By combining meteorological features (temperature, precipitation, cloud cover) with temporal patterns (hour, day of week, month, holidays), the system provides accurate traffic flow estimates that can support civil engineering decision-making.

This tool is designed for transportation engineers, urban planners, and researchers who need data-driven insights into traffic behavior for road design, signal optimization, and capacity planning.

📂 Dataset

The project uses the Metro Interstate Traffic Volume dataset from the UCI Machine Learning Repository .

  • Source: Minnesota Department of Transportation (MnDOT)
  • Location: Interstate 94 Westbound, Minneapolis–St. Paul, MN
  • Period: 2012 – 2018
  • Records: ~48,000 hourly observations
  • Target Variable: Traffic volume (vehicles/hour)
  • Features: Temperature, rain, snow, cloud cover, holiday flag, date/time

🤖 Machine Learning Model

The prediction model is built using Linear Regression from scikit-learn. While simple, linear regression provides interpretable coefficients and a solid baseline for understanding the relationship between input features and traffic volume.

  • Algorithm: Ordinary Least Squares (OLS) Linear Regression
  • Library: scikit-learn
  • Train/Test Split: 80% training / 20% testing
  • Evaluation Metrics: MAE, RMSE, R² Score
  • Feature Engineering: Hour, day-of-week, month, weekend flag extracted from timestamps

🏗️ Civil Engineering Applications

Accurate traffic volume prediction is critical for numerous aspects of civil and transportation engineering:

🛣️ Road Design & Capacity

Determine the number of lanes, pavement thickness, and geometric design based on predicted traffic loads.

🚦 Signal Optimization

Optimize traffic signal timings and phasing plans using predicted hourly traffic flows at intersections.

📋 Transportation Planning

Support long-range infrastructure planning by forecasting future traffic growth patterns.

🔧 Maintenance Scheduling

Schedule road maintenance and construction during low-traffic periods to minimize disruption.

🌍 Environmental Impact

Estimate vehicle emissions and noise pollution levels for environmental impact assessments.

💰 Economic Analysis

Evaluate cost-benefit ratios for proposed highway improvements using traffic volume projections.
